# Dronalytics Customer Segment Field

Interactive radial map of 43 candidate customer segments for Dronalytics, built for pretotyping prioritisation.

- **Ring** = distance from today (reachability)
- **Bubble size** = guesstimated market size
- **Colour** = 8-scenario strategy verdict (size x growth x competition)
- **Border** = guesstimate vs. secondary-research convergence

Tap any bubble for its full report card: guesstimate staircase, explicit assumptions, research cross-check, and strategy verdict.

Live at: https://sunnygeorge1202-eng.github.io/dronalytics-segment-field/
